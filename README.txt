ECO SPHERE — интерактивный образовательный сайт

Файлы:
- index.html — структура и тексты сайта
- style.css — оформление, адаптивность и расширенные кинематографические анимации
- script.js — навигация, появление блоков, прогресс и интерактивный список

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для публикации загрузите все три файла в один репозиторий GitHub и включите GitHub Pages.

Важно:
- Для фотографий используются внешние изображения Unsplash по URL. Для публичной публикации проверьте условия лицензии и атрибуции конкретных фотографий.
- Google Fonts и изображения загружаются из интернета.
- При желании можно заменить URL фотографий на собственные локальные файлы.
